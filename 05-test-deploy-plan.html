第一章 测试策略

本项目采用三层测试金字塔：单元测试（快速、大量）→ 集成测试（端到端验证）→ 性能压测（高并发场景模拟）。覆盖率工具使用 JaCoCo，CI 中强制门禁检查。

1.1 单元测试

框架：JUnit 5 + Mockito + Spring Boot Test
覆盖率目标：Service 层 > 80%、Mapper 层 > 60%、Controller 层 > 50%
Mock 策略：Service 测试 Mock 掉 Mapper 和外部依赖；Mapper 测试使用 H2 内存数据库或 @MybatisTest 切片

#测试场景流程验证点
1秒杀完整链路POST /login → GET /goods/{id} → POST /seckill/{id} → GET /order/{id} → POST /pay → GET /order/{id}登录返回 Token；商品详情正常；秒杀返回成功；订单状态 PAYING → PAID
2并发安全 — 100 线程抢 10 件100 个线程携带不同 Token 同时 POST /seckill/{id}（库存=10）恰好 10 个成功、90 个返回"库存不足"；MySQL 订单数 = 10；Redis 库存 = 0

4权限控制 — 买家访问管理接口用普通买家 Token 访问 GET /admin/orders返回 HTTP 403 Forbidden
5限流验证单 IP 在 1 秒内发送 20 次 POST /seckill/{id}（限流阈值 10/s）前 10 次正常响应，后续返回 HTTP 429 Too Many Requests
6Redis 与 MySQL 库存一致性执行多次秒杀 + 取消操作后对比 Redis GET stock:{id} 与 MySQL stock 字段两者数值一致
7JWT 过期拒绝访问使用过期 Token 访问需鉴权接口返回 HTTP 401 Unauthorized
8商品详情缓存命中首次 GET /goods/{id}（缓存穿透）→ 第二次 GET（缓存命中）第二次响应时间 < 首次的 50%；Redis key 存在且 TTL > 0
Testcontainers 配置要点：在 src/test/resources 下创建 application-test.yml，通过 @ActiveProfiles("test") 激活；使用 @ServiceConnection（Spring Boot 3.1+）自动注入容器连接信息，无需手动配置端口映射。

nginx.conf（动静分离 + 反向代理 + 限流）

worker_processes auto;
events {
    worker_connections 4096;
    use epoll;
}

http {
    include       /etc/nginx/mime.types;
    default_type  application/octet-stream;

    # ── 日志格式 ──
    log_format main '$remote_addr - $remote_user [$time_local] '
                    '"$request" $status $body_bytes_sent '
                    '"$http_referer" "$http_user_agent" '
                    'rt=$request_time';
    access_log /var/log/nginx/access.log main;

    # ── 性能优化 ──
    sendfile        on;
    tcp_nopush      on;
    tcp_nodelay     on;
    keepalive_timeout 65;
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml;
    gzip_min_length 1024;

    # ── 限流配置 ──
    limit_req_zone $binary_remote_addr zone=api_limit:10m rate=10r/s;
    limit_req_zone $binary_remote_addr zone=seckill_limit:10m rate=5r/s;

    # ── 上游服务 ──
    upstream seckill_backend {
        server seckill-app:8080;
        keepalive 64;
    }

    server {
        listen 80;
        server_name _;

        # ── 前端静态文件 ──
        location / {
            root /usr/share/nginx/html;
            index index.html;
            try_files $uri $uri/ /index.html;    # Vue Router history 模式
            expires 7d;
            add_header Cache-Control "public, immutable";
        }

        # ── API 反向代理（普通接口）──
        location /api/ {
            limit_req zone=api_limit burst=20 nodelay;
            proxy_pass http://seckill_backend;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_connect_timeout 5s;
            proxy_read_timeout 30s;
        }

        # ── 秒杀接口（更严格限流）──
        location /api/v1/seckill/ {
            limit_req zone=seckill_limit burst=10 nodelay;
            proxy_pass http://seckill_backend;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }

        # ── Actuator（仅内网可访问）──
        location /actuator/ {
            allow 172.0.0.0/8;
            allow 10.0.0.0/8;
            deny all;
            proxy_pass http://seckill_backend;
        }

        # ── 健康检查 ──
        location /health {
            access_log off;
            return 200 'OK';
        }
    }
}

第四章 CI/CD 流程

4.1 GitHub Actions 工作流

本项目使用 GitHub Actions 实现自动化构建、测试和部署。

Push 触发（CI）

  1. 代码检出
  2. JDK 17 + Maven 缓存
  3. 编译 mvn compile
  4. 单元测试 mvn test
  5. JaCoCo 覆盖率检查（门禁 ≥ 70%）
  6. Checkstyle 代码风格检查
  7. SpotBugs 静态分析

Tag 触发（CD）

  1. 完成 CI 全部步骤
  2. Maven 打包 mvn package
  3. Docker 多阶段构建镜像
  4. 推送镜像到 Docker Hub / ACR
  5. SSH 到服务器执行 docker compose up -d
  6. 健康检查验证部署成功

.github/workflows/ci.yml

name: Seckill CI/CD Pipeline

on:
  push:
    branches: [main, develop]
    paths-ignore: ['**.md', 'docs/**']
  pull_request:
    branches: [main]
  release:
    types: [published]    # Tag 发布触发 CD

env:
  JAVA_VERSION: '17'
  DOCKER_IMAGE: ${{ secrets.DOCKER_USERNAME }}/seckill-platform

jobs:
  # ── CI: 编译 + 测试 + 代码质量 ──
  build-and-test:
    runs-on: ubuntu-latest
    services:
      mysql:
        image: mysql:8.0
        env:
          MYSQL_ROOT_PASSWORD: root123
          MYSQL_DATABASE: seckill_test
        ports: ['3306:3306']
        options: --health-cmd="mysqladmin ping" --health-interval=10s --health-retries=5
      redis:
        image: redis:7-alpine
        ports: ['6379:6379']
        options: --health-cmd="redis-cli ping" --health-interval=10s --health-retries=5

    steps:
      - uses: actions/checkout@v4

      - name: Set up JDK ${{ env.JAVA_VERSION }}
        uses: actions/setup-java@v4
        with:
          java-version: ${{ env.JAVA_VERSION }}
          distribution: temurin
          cache: maven

      - name: Compile
        run: mvn compile -B

      - name: Unit Tests + Coverage
        run: mvn test -B -Ptest
        env:
          SPRING_PROFILES_ACTIVE: test

      - name: JaCoCo Coverage Check
        run: |
          mvn jacoco:check -B \
            -Djacoco.checks.rule.limit=0.70 \
            -Djacoco.checks.rule.counter=LINE

      - name: Checkstyle
        run: mvn checkstyle:check -B

      - name: SpotBugs
        run: mvn spotbugs:check -B

      - name: Upload Test Report
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: test-reports
          path: target/surefire-reports/

  # ── CD: 构建镜像 + 部署（仅 Tag 触发）──
  build-and-deploy:
    needs: build-and-test
    if: github.event_name == 'release'
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Login to Docker Hub
        uses: docker/login-action@v3
        with:
          username: ${{ secrets.DOCKER_USERNAME }}
          password: ${{ secrets.DOCKER_PASSWORD }}

      - name: Build and Push Docker Image
        uses: docker/build-push-action@v5
        with:
          context: .
          push: true
          tags: |
            ${{ env.DOCKER_IMAGE }}:${{ github.ref_name }}
            ${{ env.DOCKER_IMAGE }}:latest

      - name: Deploy to Server via SSH
        uses: appleboy/ssh-action@v1
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SSH_PRIVATE_KEY }}
          script: |
            cd /opt/seckill
            docker compose pull
            docker compose up -d --remove-orphans
            sleep 10
            curl -f http://localhost:8080/actuator/health || exit 1
            echo "Deployment successful!"

5.3 风险管理

风险ID风险描述概率影响应对策略责任人
