2.2 性能指标分解

秒杀接口端到端P99响应200ms分解到各环节。

时间预算（200ms）

网络5ms
鉴权10ms
限流5ms
Lua 15ms
MQ 10ms
序列化5ms
余量150ms
环节预算占比说明优化
网络5ms2.5%内环回延迟同机房部署
JWT鉴权10ms5%Token解析+签名HS256算法
限流5ms2.5%Redis INCR+EXPIRE预计算Key
Lua脚本15ms7.5%库存预减+校验预编译加载
MQ发送10ms5%RabbitMQ publish异步confirm
序列化5ms2.5%JSON+HTTP写出Jackson预编译
预留余量150ms75%GC/调度/抖动JVM调优
商品详情页(50ms)：网络3ms+鉴权5ms+Redis缓存8ms+序列化4ms+余量30ms。多级缓存(Caffeine+Redis)命中率>99%。

EmailServiceImpl核心

@Service @Slf4j
public class EmailServiceImpl implements EmailService {
    @Autowired private JavaMailSender mailSender;
    @Autowired private TemplateEngine templateEngine;

    @Async("emailExecutor")
    @Retryable(maxAttempts=3, backoff=@Backoff(delay=1000, multiplier=2))
    @Override
    public void sendRegisterVerify(String to, String name, String code) {
        Context ctx = new Context();
        ctx.setVariable("username", name);
        ctx.setVariable("verifyCode", code);
        String html = templateEngine.process("email/register-verify", ctx);
        MimeMessage msg = mailSender.createMimeMessage();
        MimeMessageHelper h = new MimeMessageHelper(msg, true, "UTF-8");
        h.setFrom(fromEmail); h.setTo(to);
        h.setSubject("【秒杀平台】注册验证码");
        h.setText(html, true);
        mailSender.send(msg);
    }
}
