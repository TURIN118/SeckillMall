DESIGN SYSTEM v2.0

SeckillMall 设计系统规范

基于 Spring Boot 高并发秒杀电商平台的前端视觉与组件规范。所有页面、原型、UI 实现均以本文件为准绳。

Vue 3.4+ Element Plus 2.x Vite 5 Pinia Vue Router 4 @element-plus/icons-vue ECharts 5

① 设计理念

秒杀场景的前端体验有三个核心诉求：紧迫感（让用户感知时间与库存压力）、即时反馈（点击后毫秒级状态变化）、不焦虑的等待（用骨架屏/进度条替代空白）。色彩以 Element Plus 默认蓝为基底、秒杀红为强调，红蓝分工避免用户混淆「普通购买」与「秒杀」。

三条不可违背的原则：
1. 价格、库存、倒计时三要素在任何卡片/页面必须视觉优先级最高；
2. 任何用户可点击的抢购类操作，必须有 loading 过渡态，禁止重复点击；
3. 空状态、错误状态、边界状态必须配图示+文案+操作引导，不允许出现「白屏」。
技术栈定位：前端基于 Vue 3 + Element Plus，所有组件优先使用 Element Plus 原生组件，仅在秒杀倒计时、秒杀卡片等业务组件上二次封装。设计令牌与 Element Plus 的 CSS 变量体系完全对齐。

⑦ Element Plus 主题定制

通过覆盖 Element Plus 的 CSS 变量实现品牌定制，无需编译 SCSS。在 src/styles/element-theme.css 中统一覆盖：

/* src/styles/element-theme.css */
:root {
  /* 主色 → Element Plus primary */
  --el-color-primary: #409eff;
  --el-color-primary-light-3: #79bbff;
  --el-color-primary-light-5: #a0cfff;
  --el-color-primary-light-7: #c6e2ff;
  --el-color-primary-light-9: #ecf5ff;
  --el-color-primary-dark-2: #337ecc;

  /* 秒杀红 → 复用 danger */
  --el-color-danger: #f56c6c;
  --el-color-danger-light-9: #fef0f0;

  /* 语义色对齐 */
  --el-color-success: #67c23a;
  --el-color-warning: #e6a23c;
  --el-color-info: #909399;

  /* 圆角 */
  --el-border-radius-base: 4px;
  --el-border-radius-small: 2px;

  /* 字体 */
  --el-font-family: 'PingFang SC', 'Microsoft YaHei', sans-serif;
}
引入方式：在 main.ts 中 import 'element-plus/dist/index.css' 之后引入此覆盖文件，确保覆盖优先级。
