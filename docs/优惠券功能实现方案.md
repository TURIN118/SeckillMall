## 一、功能概述

为秒杀商城实现完整的优惠券功能，包括：
- **领取优惠券**：用户在领券中心、商品详情页领取可用优惠券
- **使用优惠券**：结算时选择优惠券抵扣订单金额
- **管理优惠券**：后台创建/编辑/发放优惠券（已有）

### 优惠券适用范围（三层）

| 范围 | scopeType | 说明 | 展示标签 |
|------|-----------|------|----------|
| 全站通用 | `ALL` | 不限商品分类 | 不显示标签 |
| 指定分类 | `CATEGORY` | 仅该分类商品可用 | "仅限XX分类" |
| 指定商品 | `PRODUCT` | 仅该商品可用 | "仅限XX商品" |

### 优惠券类型

| 类型 | type | amount 含义 | 计算方式 | 示例 |
|------|------|------------|----------|------|
| 满减券 | `AMOUNT` | 减免金额（元） | 实付 = 适用小计 - amount | 满200减30 → 实付170 |
| 折扣券 | `DISCOUNT` | 折扣率（0~1） | 实付 = 适用小计 × amount | 满200打85折 → 实付170 |

```
│  商品列表                                     │
├─────────────────────────────────────────────┤
│  优惠券    [选择优惠券 ▼]                      │
│            ├ 不使用优惠券                      │
│            ├ ¥30 满减券（满200减30）  ✓已选    │
│            ├ 8.5折 折扣券（满100可用）         │
│            └ ¥50 满减券（满500可用）灰色不可用 │
├─────────────────────────────────────────────┤
│  优惠金额                       -¥30          │
│  商品总额                       ¥897          │
│  实付金额                       ¥867          │
├─────────────────────────────────────────────┤
│  支付方式                                      │
└─────────────────────────────────────────────┘
```

**使用逻辑**：
1. 进入结算页 → 调用 `GET /api/v1/coupons/mine?status=UNUSED` 获取未使用优惠券
2. 按订单商品筛选可用券：
   - 通用券(ALL)：订单总额 ≥ minAmount 即可用
   - 分类券(CATEGORY)：该分类商品小计 ≥ minAmount 才可用
   - 商品券(PRODUCT)：该商品小计 ≥ minAmount 才可用
3. 选择优惠券 → 实时计算优惠金额
4. 提交订单 → 传入 `userCouponId`
5. **秒杀订单不显示优惠券区**

**优惠金额计算示例**：
```
订单：手机(¥2000) + 衣服(¥500) = ¥2500

选择"¥30满减券(全站,满200)"：
  适用小计 = ¥2500，满足门槛
  优惠 = ¥30，实付 = ¥2470

选择"8.5折折扣券(仅限手机,满1000)"：
  适用小计 = ¥2000（仅手机），满足门槛
  优惠 = ¥2000 × (1-0.85) = ¥300，实付 = ¥2200

选择"¥50满减券(仅限衣服,满300)"：
  适用小计 = ¥500（仅衣服），满足门槛
  优惠 = ¥50，实付 = ¥2450
```

## 五、优惠券规则

| 规则 | 说明 |
|------|------|
| 满减券(AMOUNT) | 适用商品小计 ≥ minAmount 时，减 amount 元 |
| 折扣券(DISCOUNT) | 适用商品小计 ≥ minAmount 时，适用商品 × amount 折 |
| 一单一券 | 每个订单最多使用一张优惠券 |
| 仅普通订单 | 秒杀订单不可使用优惠券 |
| 有效期 | startTime ≤ 当前时间 ≤ endTime 才可使用 |
| 核销时机 | 支付成功时核销(UNUSED→USED)，取消订单时回退(USED→UNUSED) |
| 防超卖 | 领取时原子更新 received_count，WHERE received_count < total_count |
| 防重复领取 | (user_id, coupon_id) 唯一索引兜底 |

### 状态流转
```
领取 → UNUSED(未使用) → 支付成功 → USED(已使用) → 取消/退款 → UNUSED(恢复)
UNUSED → 超过有效期 → EXPIRED(已过期)
```

## 九、风险与注意事项

| 风险 | 应对 |
|------|------|
| 优惠券核销并发 | useCoupon 使用乐观锁 WHERE status = 'UNUSED' 保证原子性 |
| 优惠券过期检查 | 可复用现有定时任务，扫描 UNUSED 且超过 endTime 的记录改为 EXPIRED |
| 金额精度 | 全程使用 BigDecimal，避免浮点误差 |
| 秒杀订单误用优惠券 | 前端不显示选择区 + 后端强制校验订单类型 |
| 结算页适用商品小计计算 | 按 scope 筛选订单中匹配的商品计算小计，不匹配的商品不参与优惠 |
