## 评级方法说明

### 评级流程

1. **提取结果项**：从 knip JSON 输出中提取每个未使用的文件、导出、类型
2. **引用验证**：使用 Grep 工具在 `src/**/*.{vue,ts,js,tsx,jsx}` 范围内搜索每个结果项的所有可能引用方式
3. **置信度评级**：根据搜索结果评定为高/中/低置信度
4. **记录依据**：记录搜索关键词、匹配数、评级结论和依据

### 评级标准

| 评级 | 标准 | 建议操作 |
|------|------|----------|
| 高置信度 | 经验证确认无任何引用（0匹配或仅定义处/注释处匹配） | 可安全删除 |
| 中置信度 | 存在少量疑似引用（字符串引用、内部使用、注释引用），需人工判断是否为实际使用 | 建议人工确认后再处理 |
| 低置信度 | 存在明确引用，或 knip 解析有误（如同文件内类型继承未被识别） | **不应删除**，需仔细审查 |

### 搜索策略

- **文件**：搜索文件名、路径片段、可能的 import 语句、路由配置中的引用
- **导出**：搜索导出名称，区分定义处与引用处
- **类型**：搜索类型名称，区分类型引用与同名变量/函数/注释
- **动态导入**：检查 `import()` 动态导入和路由配置中的组件引用
- **路径别名**：同时搜索 `@/` 别名和相对路径两种形式

## 误报风险分析

### 高风险类别（knip 易误报）

- **同文件内类型继承/引用**：knip 对 `extends PageRequest`、`items: NormalOrderItem[]` 等同文件内引用识别不完整，可能误报为未使用。本报告已通过 grep 验证识别出 `PageRequest` 和 `NormalOrderItem` 两个误报。
- **.d.ts 类型文件**：`auto-imports.d.ts`、`components.d.ts` 等自动生成的类型声明文件可能涉及隐式引用，本报告未将其纳入扫描范围（已在 knip.json 中通过 entry 配置规避）。

### 中风险类别

- **Vue 组件的动态引用**：Vue 文件可能通过路由配置 `() => import('@/views/xxx.vue')` 动态引用。本报告已逐一检查 router/index.ts，确认所有路由引用的组件，未使用的 Vue 文件均未在路由中注册。
- **字符串引用**：组件名可能以字符串形式出现在路由名称数组、菜单配置等位置（如 `MyCoupons`），需人工判断是否为实际业务引用。
