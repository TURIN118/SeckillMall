# 商品添加字段详细说明文档

> 本文档详细说明在后台管理系统中添加商品时，需要填写的所有字段内容、校验规则及注意事项。

---

## 一、字段总览

| 序号 | 字段名 | 中文名 | 类型 | 是否必填 | 前端控件 | 后端校验 |
|:---:|---------|--------|------|:---:|----------|----------|
| 1 | productName | 商品名称 | String | ✅ 必填 | el-input (文本输入框) | 非空，2~100字符 |
| 2 | categoryId | 商品分类 | Long | ✅ 必填 | el-cascader (级联选择器) | 非空，需为有效分类ID |
| 3 | originalPrice | 商品价格 | BigDecimal | ✅ 必填 | el-input-number (数字输入框) | 非空，≥ 0.01 |
| 4 | stock | 库存数量 | Integer | ✅ 必填 | el-input-number (数字输入框) | 非空，≥ 0 |
| 5 | mainImage | 商品主图 | String (URL) | ⚠️ 建议填写 | ImageUploader (单图上传) | 无强制校验 |
| 6 | images | 商品图片 | List&lt;String&gt; (URL数组) | ⚠️ 建议填写 | ImageUploader (多图上传，最多5张) | 无强制校验 |
| 7 | description | 商品简介 | String | ❌ 可选 | el-input textarea (文本域) | 最大500字符 |
| 8 | detailHtml | 商品详情 | String (HTML) | ❌ 可选 | wangEditor (富文本编辑器) | 无长度限制 |

## 二、各字段详细说明

### 1. 商品名称 (productName)

- **含义**：商品的显示名称，展示在商品列表、详情页、购物车等位置
- **数据类型**：字符串
- **必填**：是
- **长度限制**：2 ~ 100 个字符
- **前端控件**：文本输入框，带字数统计（show-word-limit），最大输入100字符
- **后端校验**：
  - `@NotBlank(message = "商品名称不能为空")` — 不能为空白
  - `@Size(max = 100, message = "商品名称最大 100 字符")` — 最大100字符
- **数据库字段**：`t_product.name`，类型 `VARCHAR(200) NOT NULL`
- **填写建议**：名称应简洁明了，包含品牌+型号+关键规格，如"iPhone 15 Pro Max 256GB"

### 2. 商品分类 (categoryId)

- **含义**：商品所属的分类，用于分类浏览和筛选
- **数据类型**：长整型（分类ID）
- **必填**：是
- **前端控件**：级联选择器（el-cascader），支持选择一级分类或二级分类
  - `checkStrictly: true` — 允许选择任意层级（一级或二级均可）
  - 分类数据从后端 `getCategoryTree()` API 实时获取
- **后端校验**：`@NotNull(message = "分类 ID 不能为空")` — 不能为空
- **数据库字段**：`t_product.category_id`，类型 `BIGINT NOT NULL`
- **填写建议**：
  - 尽量选择二级分类（叶子分类），如"智能手机"而非"手机数码"
  - 如商品跨越多个分类，选择最贴切的那个
  - 分类需在分类管理中提前创建

### 3. 商品价格 (originalPrice)

- **含义**：商品的销售单价（原价），单位为元
- **数据类型**：高精度十进制数（BigDecimal）
- **必填**：是
- **前端控件**：数字输入框（el-input-number）
  - 最小值：0.01
  - 精度：2位小数
  - 步进：1
- **后端校验**：
  - `@NotNull(message = "商品价格不能为空")` — 不能为空
  - `@DecimalMin(value = "0.01", message = "商品价格必须大于 0")` — 最小0.01
- **数据库字段**：`t_product.original_price`，类型 `DECIMAL(10,2) NOT NULL`
- **填写建议**：填写实际销售价格，精确到分（两位小数），如 9999.00

### 4. 库存数量 (stock)

- **含义**：商品的可用库存数量
- **数据类型**：整数
- **必填**：是
- **前端控件**：数字输入框（el-input-number）
  - 最小值：0
  - 步进：1
- **后端校验**：
  - `@NotNull(message = "库存数量不能为空")` — 不能为空
  - `@Min(value = 0, message = "库存数量不能小于 0")` — 最小0
- **数据库字段**：`t_product.stock`，类型 `INT NOT NULL DEFAULT 0`
- **填写建议**：填写真实可售库存，库存为0时商品会显示"售罄"

### 5. 商品主图 (mainImage)

- **含义**：商品的主展示图片，显示在商品列表卡片和详情页顶部
- **数据类型**：字符串（图片URL）
- **必填**：否（但强烈建议填写）
- **前端控件**：ImageUploader 组件（单图上传）
  - 最多上传 1 张
  - 支持图片格式：JPG、PNG、WebP 等
  - 上传后将图片URL存入 mainImage 字段
- **后端校验**：无强制校验
- **数据库字段**：`t_product.main_image`，类型 `VARCHAR(255)`
- **填写建议**：
  - 主图是商品的"门面"，务必上传高质量图片
  - 建议尺寸：800×800 像素，正方形比例
  - 图片需清晰、无水印、背景简洁

### 6. 商品图片 (images)

- **含义**：商品的多张展示图片，在详情页轮播展示
- **数据类型**：字符串数组（图片URL列表）
- **必填**：否（但建议至少上传1-3张）
- **前端控件**：ImageUploader 组件（多图上传）
  - 最多上传 5 张
  - 支持拖拽排序
- **后端校验**：无强制校验
- **数据库字段**：`t_product.images`，类型 `JSON`（存储URL数组）
- **填写建议**：
  - 建议上传商品不同角度、细节的图片
  - 第一张图片通常作为默认展示图
  - 图片尺寸建议统一，如 800×800

### 7. 商品简介 (description)

- **含义**：商品的简短文字描述，展示在商品列表和详情页摘要区域
- **数据类型**：字符串（纯文本）
- **必填**：否
- **长度限制**：最大 500 字符
- **前端控件**：文本域（el-input textarea）
  - 3行高度
  - 带字数统计
  - 最大500字符
- **后端校验**：`@Size(max = 500, message = "商品简述最大 500 字符")`
- **数据库字段**：`t_product.description`，类型 `TEXT`
- **填写建议**：用一两句话概括商品的核心卖点、关键参数，如"A17 Pro芯片，4800万像素主摄，钛金属设计"

### 8. 商品详情 (detailHtml)

- **含义**：商品的详细描述，支持富文本格式（HTML），展示在详情页"商品详情"区域
- **数据类型**：字符串（HTML内容）
- **必填**：否
- **前端控件**：wangEditor 富文本编辑器
  - 支持文字排版（加粗、斜体、下划线、颜色等）
  - 支持插入图片、表格、列表
  - 支持标题层级、对齐方式
  - 编辑器高度 360px
- **后端校验**：无长度限制（数据库字段为 TEXT 类型）
- **数据库字段**：`t_product.detail_html`，类型 `TEXT`
- **填写建议**：
  - 详细描述商品的规格参数、功能特点、包装清单等
  - 可插入商品详情图（长图）
  - 如不填写，详情页将回退显示商品简介（description）

### 9. 商品状态 (status)

- **含义**：商品的上下架状态
- **数据类型**：枚举
- **必填**：是（默认"上架"）
- **前端控件**：单选按钮组（el-radio-group）
  - 上架 (ON_SALE) — 商品在前台可见可购买
  - 下架 (OFF_SHELF) — 商品在前台不可见
- **后端校验**：枚举值校验，仅允许 ON_SALE 或 OFF_SHELF
- **数据库字段**：`t_product.status`，类型 `ENUM('ON_SALE','OFF_SHELF') NOT NULL DEFAULT 'ON_SALE'`
- **填写建议**：
  - 新增商品通常选择"上架"
  - 暂不售卖的商品选择"下架"
  - 下架商品不会出现在前台商品列表和搜索结果中

## 三、数据库字段映射关系

| 前端表单字段 | 后端DTO字段 | 数据库字段 | 数据库类型 |
|-------------|------------|-----------|-----------|
| productName | productName | name | VARCHAR(200) NOT NULL |
| categoryId | categoryId | category_id | BIGINT NOT NULL |
| originalPrice | originalPrice | original_price | DECIMAL(10,2) NOT NULL |
| stock | stock | stock | INT NOT NULL DEFAULT 0 |
| mainImage | images[0] | main_image | VARCHAR(255) |
| images | images | images | JSON |
| description | description | description | TEXT |
| detailHtml | detailHtml | detail_html | TEXT |
| status | status | status | ENUM('ON_SALE','OFF_SHELF') |

> **注意**：前端 `mainImage` 和 `images` 在提交时会合并为一个 `images` 数组（主图作为 images[0]，多图作为 images[1..n]）。后端 `ProductServiceImpl` 在保存时会将 images[0] 提取为 `main_image` 字段。

## 四、自动填充字段（无需手动填写）

以下字段由系统自动维护，添加商品时无需关心：

| 字段 | 数据库字段 | 说明 |
|------|-----------|------|
| id | id | 主键，雪花算法自动生成 |
| salesCount | sales_count | 累计销量，初始为0，下单时自动增加 |
| cartCount | cart_count | 加购数量，初始为0，购物车操作时维护 |
| favoriteCount | favorite_count | 收藏数量，初始为0，收藏操作时维护 |
| isDeleted | is_deleted | 逻辑删除标记，初始为0 |
| createTime | create_time | 创建时间，自动填充 |
| updateTime | update_time | 更新时间，自动填充 |

## 五、API 接口说明

### 新增商品

```
POST /api/v1/admin/products
```

**请求头**：需携带 JWT Token（管理员/卖家权限）

**请求体**（JSON）：
```json
{
  "productName": "iPhone 15 Pro Max 256GB",
  "categoryId": 101,
  "originalPrice": 9999.00,
  "stock": 500,
  "images": ["https://example.com/main.jpg", "https://example.com/1.jpg"],
  "description": "A17 Pro芯片，4800万像素主摄，钛金属设计",
  "detailHtml": "<p>商品详情内容...</p>",
  "status": "ON_SALE"
}
```

**响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": { "id": 1234567890 }
}
```

### 编辑商品

```
PUT /api/v1/admin/products/{id}
```

请求体同新增，所有字段均可修改。

## 六、操作流程

1. **进入商品管理**：后台管理 → 商品管理 → 点击"新增商品"按钮
2. **填写表单**：
   - 输入商品名称（2~100字符）
   - 选择商品分类（级联选择器，选一级或二级分类）
   - 输入商品价格（≥ 0.01元）
   - 输入库存数量（≥ 0）
   - 上传商品主图（1张，建议800×800）
   - 上传商品图片（最多5张）
   - 输入商品简介（可选，≤ 500字符）
   - 编辑商品详情（可选，富文本）
   - 选择商品状态（上架/下架）
3. **提交保存**：点击"保存"按钮，前端校验通过后提交到后端
4. **后端校验**：后端进行参数校验（@NotBlank、@NotNull、@Size、@DecimalMin、@Min）
5. **保存成功**：返回商品ID，跳转回商品管理列表

---

## 七、注意事项

1. **禁止模拟数据**：所有字段需填写真实数据，图片需实际上传到服务器
2. **图片上传**：图片通过后端文件上传接口上传，返回URL后存入 images 字段
3. **分类依赖**：添加商品前需先在"分类管理"中创建好分类
4. **价格精度**：价格精确到分（两位小数），使用 BigDecimal 避免浮点误差
5. **富文本安全**：detailHtml 字段不进行 XSS 清洗以保留合法 HTML 标签，需确保编辑器内容可信
6. **主图与多图关系**：前端将主图作为 images[0]，多图作为 images[1..n] 合并提交；后端拆分存储为 main_image 和 images
7. **下架商品**：下架商品不在前台展示，但后台仍可查看和编辑
8. **库存为0**：库存为0的商品仍可上架，但前台显示"售罄"，用户无法购买
